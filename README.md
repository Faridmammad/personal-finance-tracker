# 💸 Personal Finance Tracker

A simple and clean React app for tracking personal income and expenses by category and month. Easily visualize your spending habits and manage your budget.

🔗 **Live Demo**: [https://personal-finance-tracker-sandy-three.vercel.app](https://personal-finance-tracker-sandy-three.vercel.app)

## ✨ Features

- Add income or expenses with category selection
- Filter transactions by month
- View category-wise expenses in a pie chart
- Real-time balance calculation
- LocalStorage support for persistence

## 🚀 Getting Started

### Install dependencies

```bash
npm install
```

### Run the app locally

```bash
npm start
```

The app will run at: [http://localhost:3000](http://localhost:3000)

## 🛠 Tech Stack

- React (Create React App)
- Recharts
- SCSS
- LocalStorage
